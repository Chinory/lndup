位置2的字节：0x03 vs 0x04。不同，differingPosition=2.

分组后，创建两个子节点，每个子节点currentPosition=3（超过fileSize=3），所以子节点的startCompare会立即返回，保留各自的文件。这样，每个子节点有一个文件，满足条件。

如果两个文件内容完全相同，则根节点的循环会一直增加到currentPosition=3，此时超过fileSize，停止循环，differingPosition仍为null，节点保留两个文件，说明它们相同。

另一个情况，三个文件，其中两个在位置0不同：

文件A: 0x00

文件B: 0x01

文件C: 0x01

根节点currentPosition=0，读取三个文件的0位置，得到0x00,0x01,0x01。不全相同，differingPosition=0。分组后，0x00的组有文件A，0x01的组有B和C。创建两个子节点。子节点A的currentPosition=1，超过fileSize=1，所以不处理。子节点B的currentPosition=1，此时它们的文件B和C的size是1，currentPosition=1 >= size，所以子节点B的startCompare返回，保留两个文件，因为它们的content相同。

这说明，在子节点B中，文件B和C的内容相同，所以被保留在同一个节点中。

这样符合用户需求。

现在，这个设计应该可以工作。

接下来，编写代码：

首先，需要引入fs模块的promises：

const fs = require('fs').promises;

然后，实现readByteAt函数：

async function readByteAt(filePath, position) {

const fd = await fs.open(filePath, 'r');

try {

const buffer = Buffer.alloc(1);

const { bytesRead } = await fd.read(buffer, 0, 1, position);

if (bytesRead === 0) {

return null;

}

return buffer[0];

} finally {

await fd.close();

}

}

然后，LazyDiffNode类的实现：

class LazyDiffNode {

constructor(filesWithSize, currentPosition) {

this.files = filesWithSize; // Array of { path: string, size: number }

this.currentPosition = currentPosition;

this.children = new Map(); // Map<number | 'EOF', LazyDiffNode>

}

static async create(filePaths) {

const filesWithSize = await Promise.all(

filePaths.map(async (path) => {

const stat = await fs.stat(path);

return { path, size: stat.size };

})

);

const sizes = filesWithSize.map(f => f.size);

if (new Set(sizes).size !== 1) {

throw new Error('All files must have the same size');

}

return new LazyDiffNode(filesWithSize, 0);

}

async startCompare() {

if (this.files.length <= 1) {

return;

}

const fileSize = this.files[0].size;

let currentPosition = this.currentPosition;

let differingPosition = null;

let bytes = [];

while (differingPosition === null && currentPosition < fileSize) {

// 读取所有文件在currentPosition处的字节

bytes = await Promise.all(

this.files.map(async (file) => {

if (currentPosition >= file.size) {

return null;

}

return await readByteAt(file.path, currentPosition);

})

);

const firstByte = bytes[0];

const allSame = bytes.every(b => b === firstByte);

if (!allSame) {

differingPosition = currentPosition;

} else {

currentPosition++;

}

}

if (differingPosition === null) {

// 所有文件内容完全相同

return;

}

this.currentPosition = differingPosition;

// 分组文件

const groups = new Map();

for (let i = 0; i < bytes.length; i++) {

const byte = bytes[i];

const file = this.files[i];

const key = byte !== null ? byte : 'EOF'; // 使用 'EOF' 作为超出文件长度的键

if (!groups.has(key)) {

groups.set(key, []);

}

groups.get(key).push(file);

}

// 创建子节点并递归比较

for (const [key, groupedFiles] of groups) {

const childNode = new LazyDiffNode(groupedFiles, differingPosition + 1);

this.children.set(key, childNode);

await childNode.startCompare();

}

}

}

这样，用户可以通过LazyDiffNode.create(filePaths)来创建根节点，并调用startCompare()方法启动比较过程。

例如：

async function main() {

const filePaths = ['file1.bin', 'file2.bin', 'file3.bin'];

const rootNode = await LazyDiffNode.create(filePaths);

await rootNode.startCompare();

// 之后可以遍历树结构，查看每个节点的文件分布

}

main().catch(console.error);

需要注意的是，当文件很大时，逐个字节比较可能会导致性能问题。但根据用户的需求，这是必须的。

另外，处理错误的情况，比如文件无法读取，需要适当处理，比如在readByteAt中抛出错误，外层捕获。

总结：

- 每个LazyDiffNode负责比较当前position的字节，找到差异后分组。

- 使用异步API读取每个文件的字节。

- 文件大小相同，在创建节点时验证。

- 当所有文件的字节都相同，包括EOF时，节点保留所有文件。

- 子节点从差异位置的下一个位置继续比较。

现在，这个实现应该满足用户的需求。
